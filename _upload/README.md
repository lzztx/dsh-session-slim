# DSH 会话只读体检

一个 DSH（DeepSeek Harness）长会话的**只读体检工具**。给已经聊了很久、舍不得换、但窗口开始卡住的会话用：先看清日志结构、压缩发生在哪、遮蔽了多少事件，再决定要不要走瘦身。

**这个工具不修改任何会话档。** 它只读取你指定的本地快照，报告结构与计数，不输出正文、摘要原文、会话 ID 和路径。

> **它解决不了什么**：上下文压缩导致的失忆，是模型上下文本身的限制，这个工具改不了。它能做的是让瘦身之后的会话比新开一条恢复得快——旧话都在冷档里，按索引能查回。

## 快速开始

入口为 `dsh-session-inspect.mjs`。使用 Node.js 24，在本目录运行合成快照测试：

```bash
node ./dsh-session-inspect.mjs ./sample-session.v4.jsonl.zstd
node ./dsh-session-inspect.mjs ./sample-session.v4.jsonl.zstd --json
```

预期为 7 条事件、1 次压缩、前后助手事件样本 1000 → 250 tokens。随包快照是独立构造的体检样本。

用本机离线副本检查时，把示例文件名换成明确的快照路径。可加 `--cold` 指定冷档副本，再加 `--cold-sha256` 和事前登记的摘要核对字节一致性。

工具在本地只读运行，支持 v4 Zstd/JSONL，输入上限 64 MiB，解压上限 128 MiB。

## 进一步

体检结果用于盘点日志结构和用量样本。活动上下文及桌面可恢复性需要同版本原生验收。裁切与回退方法见 [Agent 手册](DSH同ID会话瘦身_Agent手册_公开稿.md)。
